# 🌙 Mossbell Hollow

### An Enchanted Interactive Cottage & Garden Experience

> *Somewhere between the moonlight and the garden, there's a little cottage waiting for you.*

Mossbell Hollow is an immersive, interactive 3D cottage experience designed to feel like a tiny magical exploration game rather than a traditional website. Explore an enchanted garden, discover hidden interactions, brew a cozy drink, open magical storybooks, and make a wish beneath the moonlight.

## 🌐 Explore the Experience

✨ **Live Website:** [mossbellhollow.netlify.app](https://mossbellhollow.netlify.app/)

💻 **GitHub Repository:** [richhyyy/mossbell-hollow](https://github.com/richhyyy/mossbell-hollow)

## ✨ Features

- 🏡 **Interactive Cottage:** Explore a cozy cottage with dusty-rose walls, a wine-brown roof, and warm ivory details.
- 🌿 **Enchanted Garden:** Discover the pond, greenhouse, wishing well, and illuminated garden.
- ☕ **Magical Coffee Station:** Choose your favorite drink and enjoy a cozy brewing animation.
- 📚 **Interactive Storybooks:** Open books to uncover short, original stories.
- 🎵 **Vintage Music Corner:** Discover a magical music box and its nostalgic atmosphere.
- 🪙 **Wishing Well:** Make a wish and experience a magical coin-dropping animation.
- 📝 **Kindness Wall:** Share and explore uplifting community notes.
- ✨ **Ambient Effects:** Experience glowing fairy lights, fireflies, warm lighting, and a dreamy twilight atmosphere.
- 🐾 **Neo's Cozy Corner:** A special resting spot for Neo, the fluffy companion.

## 🎨 Design & Atmosphere

Mossbell Hollow combines a vintage cottage aesthetic with a dark, enchanted-garden atmosphere.

- Dusty rose, sage green, and warm ivory colour palette
- Natural wooden details and glowing signs
- Moonlit skies and ambient lighting
- Interactive objects and hidden discoveries
- A cozy exploration experience instead of a conventional scrolling layout

## 🛠️ Tech Stack

- **HTML5** — Website structure
- **CSS3** — Styling, animations, and visual effects
- **JavaScript** — Interactions and dynamic behaviour
- **Three.js** — 3D graphics and rendering
- **Supabase** — Community notes storage

## 🚀 Run Locally

### Prerequisites

A modern web browser and a local development server if required by the project.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/richhyyy/mossbell-hollow.git
   ```

2. Navigate to the project directory:

   ```bash
   cd mossbell-hollow
   ```

3. Open `index.html` in your browser or launch the project using a local development server.

*If the project uses external services or requires configuration, set up the necessary credentials and environment variables before running it locally.*
